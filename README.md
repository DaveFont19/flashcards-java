General Description

As a software developer, I wanted to increase my knowledge of Android development skills by building a native mobile app from scratch using Java in Android Studio.
The Flashcard app lets a user browse a set of flashcards. When the user opens the app, it shows a list of flashcards; tapping one opens a study screen showing a question. Touching the card flips it to reveal the asnwer, and stwo buttons (Next/Previous), they move through the rest of the set.
